# WHITE FAMILY0 — Website

A single-page, static brand site for WHITE FAMILY0.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static server.

## Deploy
This folder is ready for Vercel, Netlify, GitHub Pages, or any static hosting provider.

## Customize
- Replace placeholder email in `index.html`.
- Replace `#` links for Snow White Dreams, Ward, and Aster with real URLs.
- The primary logo asset is in `assets/white-family0-logo.png`.
- Main visual identity: near-black + electric violet + small cyan accents.
